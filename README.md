# 萬能考場作文：理論與實作

給學生與家長的 3D 課程介紹島。可平移、旋轉、縮放地圖，探索教學理念、課堂方式、學生成果及顧慮，並整理諮詢提綱。

目標網址：https://khlin712.github.io/gsat-writing-class-island/

## 本機預覽與測試

`npm start`（Python 3），開啟 http://127.0.0.1:4173/ 。

`npm test`（Node.js），不需安裝套件。

## 版面與互動

- 視覺密度依參考站前端量測調整（dist/benchmark.css，最後載入）：地圖滿版、索引 320px 毛玻璃浮層、無襯線粗體標題、44px 按鈕、56px 主題列、360px 卡片；手機工具收進「工具」按鈕，清單半高時只留問題。量測表見 research/PUMA-VISUAL.md。

- 重點圖釘：選一座島後，島上立起「了解重點」圖釘 ①②③；圖釘、卡片重點列、索引重點列滑過時一起亮起，點任一處都會拉近鏡頭並打開該重點卡片（麵包屑可回到主題、上一個／下一個、可把問題加入提問）。選取的島有深色外框，其他島名淡化。
- 工具列「時段」依序切換白天、黃昏、夜晚、清晨；「鳥瞰」從正上方看九座島。

- 天空之島（dist/sky.js）：島嶼懸浮在天空中，底下是岩石倒錐、漂浮小石與兩道小瀑布；四周有天色漸層、遠方雲海、島緣雲絮和慢慢飄移的雲環。夜間配色換成深藍夜空、偏藍的雲與星星。系統設定「減少動態」時雲和小石不移動。

版面骨架對標參考站的「地圖滿版＋索引」結構（只對標行為與層級，不使用對方的程式、美術、文字或品牌）：

- 桌面：3D 地圖佔滿左側；左上品牌浮卡、其下地圖工具（放大／縮小／旋轉／名牌／關聯／暫停／時段／鳥瞰），右上為全景、清單、討論清單、關於、操作說明。右側是課程索引：標題與統計、探索問答卡、家長／學生／認識老師入口、搜尋、「常見問題／主題島」切換，主題列可展開了解重點。
- 詳細卡片浮在地圖左側，索引保持可見並標示目前主題；鏡頭飛到島時避開上方工具、左側卡片與下方說明列（`motion.js` 的 `mapInsets`）。「清單」可收起索引讓地圖變寬。
- 手機：地圖全螢幕，問題清單是底部面板（預設半高，可上拉全高、下拉收成細條；「清單」按鈕同樣可切換）。詳細卡片從底部升起，把手可在約1/3與全高間切換，再下拉關閉；開卡時清單暫收，關卡後恢復。
- 全景視角以投影檢查九座島都落在未被遮住的範圍內，再決定鏡頭距離；直式手機加大視角以容納整座群島。
- 拖曳像地圖（dist/gestures.js）：手指或游標按住的那塊地面會一直跟著走，放手前快速一甩會依速度再滑行一段（最多約目前視距的 18%），停住再放手就不滑。右鍵或「旋轉」模式拖曳旋轉。
- 滾輪往游標所在處平滑縮放，單次滾動最多縮放 1.5 倍。
- 手機雙指：捏合以兩指中間為中心縮放、轉動旋轉、同向滑動平移；兩指並排一起上下滑動則傾斜視角。手指落在島名上也算數，從島名開始拖曳不會誤開卡片。拖曳或滾輪會取消飛行。系統設定「減少動態」時直接切換。
- 首次造訪顯示三步導覽（`writing-island-onboarded`），不動到收藏、筆記與問題（`writing-island-course`，格式不變）。
- 手動驗收可在主控台執行 `__islandView()` 讀取鏡頭目標、距離與角度（唯讀）。

文字層級沿用 `dist/readability.css`，版面骨架在最後載入的 `dist/shell.css`。對標紀錄見 [research/SHELL-LAYOUT.md](research/SHELL-LAYOUT.md)，前輪見 [research/SURFACES-REVIEW.md](research/SURFACES-REVIEW.md)、[research/GAP-ANALYSIS.md](research/GAP-ANALYSIS.md)。

## GitHub Pages

儲存庫 Settings → Pages → Source 選 Deploy from a branch，使用 gh-pages 分支與 /(root)。main 保存完整原始碼，gh-pages 保存 dist/ 的網站內容。所有網站資源使用相對路徑，可在 /gsat-writing-class-island/ 下運作。

修改後先執行 npm test，再提交 main 並推送；發布網站使用：

```sh
git push origin main
git subtree push --prefix dist origin gh-pages
```

目前帳號的自訂 GitHub Actions 工作因付款／額度狀態無法啟動，因此使用 Pages 原生分支發布，未變更帳務設定。

## 建築與主題關聯

`dist/architecture.js` 以原創幾何建立九種課程微縮建築與隨時段切換的窗光。這些是主題示意，並非真實授課場地。

「主題關聯」清單可搜尋既有主題的20組連結；也可直接點地圖線段，查看兩端主題、繼續探索或把關聯問題加入討論提綱。卡片上的文案是探索問題，並非老師已確認的教學做法／成效。前端對標證據與驗證限制見 [research/ARCHITECTURE-RELATIONS.md](research/ARCHITECTURE-RELATIONS.md)。

## 七站旅程

整座島外圍有一條七站旅程，包住中間的九座主題島（`dist/summit.js` 管位置與路線，`dist/journey.js` 管文字與資料）：

1. **① 起點**：「為什麼高中一定要學國寫？」，在畫面最前面中央。
2. **② 入口指引牌**：像登山步道入口的告示牌，分出三條路。
   - **岩漿洞**和**懸崖**是死路：學生走進去會掉下去，再回到起點（`RESTART`）。
   - **陡峭山壁**是唯一的上山路，學生會沿岩壁慢慢爬上去。
   - 三條路的說明是比喻，指的是練習方式，不是任何老師或補習班。
3. **③ 走上橋**：從山壁頂通到獎盃，代表「我能引導你走向正確的路」。點獎盃或橋，橋會由下而上一階一階亮起；獎盃一直維持金光。
4. **④ 大學**：參考國立臺灣大學總圖書館的形象，沒有任何名稱或標誌。點開可看學生回饋。學生走到大學後分兩種：一半走進門口消失，再從 `SPAWN_FROM`（目前是 ① 起點）重新出發；另一半不進門，繼續往行事曆、報名、聯繫走。要換重新出發的地點，只改 `dist/summit.js` 的 `SPAWN_FROM`。
5. **⑤ 課程行事曆**：大學旁有往下的石階梯通到這裡。有開班的年級接著報名；年紀還小的只顯示預先登記表單。
6. **⑥ 報名**：私訊索取線上教學視聽、報名表單。
7. **⑦ 聯繫**：聯繫方式，旁邊步道接回起點。

**要填的資料都在 `dist/journey.js`**，留空時網站一律顯示「待老師提供」：

- 起點、橋的說明文字：`STATIONS` 的 `body`。
- 學生回饋：`FEEDBACK`，請先取得學生同意。
- 開班資訊：`CLASSES`，`status` 填 `'open'` 或 `'preregister'`。
- 表單與私訊連結：`LINKS`，必須是 `https://` 開頭。
- 聯繫方式：`CONTACTS`。

連結都會開到外部頁面；網站本身不會代為傳送訊息，也不收集資料。

## 島上的人物

- 人物有臉、頭髮、手腳與配件，走路時手腳交錯（`dist/people.js`）。每個人物只有 6 次繪製，40 人左右也不會太重。
- 人物共 58 位（`dist/walkers.js`）：
  - **學生 47 位**：對應老師目前的教學人數，寫在 `STUDENTS`，人數改變時只改這個數字。
    - 其中 7 位在有實體步道的關聯上抱著筆記本來回走，點下去會打開那條關聯。
    - 其餘學生在島與島之間走動；同時最多 6 位會走到指引牌選路：走錯掉下去回到起點，爬上山壁的過橋、經過獎盃到大學，一半進門消失、再從起點重新出發，一半繼續走向行事曆、報名、聯繫；總數維持 47 位。
  - **家長**：每座島 1 位，身形稍高，在島前步道散步。
  - **導覽員**：依 01→09 順序巡島，上下 05 都走階梯。
  - **我的角色**：右上「角色」。可設定名字、身分、髮型、衣服顏色，存在 `writing-island-avatar`。行程可選自由漫步、自動逛逛、點地圖指定、前往某座島。
- 點人物時鏡頭會飛近並跟隨；拖曳、滾輪或雙指操作就停止跟隨。工具列「人物」可隱藏其他人物，「日誌」記錄抵達紀錄。暫停或系統減少動態時，人物會停下來。
- 所有人物都是地圖角色，不代表老師本人、真實學生、家長或案例。
