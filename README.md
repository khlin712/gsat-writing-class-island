# 萬能考場作文：理論與實作

給學生與家長的 3D 課程介紹島。可平移、旋轉、縮放地圖，探索教學理念、課堂方式、學生成果及顧慮，並整理諮詢提綱。

目標網址：https://khlin712.github.io/gsat-writing-class-island/

## 本機預覽與測試

`npm start`（Python 3），開啟 http://127.0.0.1:4173/ 。

`npm test`（Node.js），不需安裝套件。

## 版面與互動

- 視覺密度依參考站前端量測調整（dist/benchmark.css，最後載入）：地圖滿版、索引 320px 毛玻璃浮層、無襯線粗體標題、44px 按鈕、56px 主題列、360px 卡片；手機工具收進「工具」按鈕，清單半高時只留問題。量測表見 research/PUMA-VISUAL.md。

- 重點圖釘：選一座島後，島上立起「了解重點」圖釘 ①②③；圖釘、卡片重點列、索引重點列滑過時一起亮起，點任一處都會拉近鏡頭並打開該重點卡片（麵包屑可回到主題、上一個／下一個、可把問題加入提問）。選取的島有深色外框，其他島名淡化。
- 工具列「時段」依序切換白天、黃昏、夜晚、清晨；「鳥瞰」從正上方看九座島。

- 天空之島（dist/sky.js）：島嶼懸浮在天空中，底下是岩石倒錐、漂浮小石與兩道小瀑布；四周有天色漸層、遠方雲海、島緣雲絮和慢慢飄移的雲環。夜間配色換成深藍夜空、偏藍的雲與星星。系統設定「減少動態」時雲和小石不移動。

版面骨架對標參考站的「地圖滿版＋索引」結構（只對標行為與層級，不使用對方的程式、美術、文字或品牌）：

- 桌面：3D 地圖佔滿左側；左上品牌浮卡、其下地圖工具（放大／縮小／旋轉／名牌／關聯／暫停／時段／鳥瞰），右上為全景、清單、討論清單、關於、操作說明。右側是課程索引：標題與統計、探索問答卡、家長／學生／認識老師入口、搜尋、「常見問題／主題島」切換，主題列可展開了解重點。
- 詳細卡片浮在地圖左側，索引保持可見並標示目前主題；鏡頭飛到島時避開上方工具、左側卡片與下方說明列（`motion.js` 的 `mapInsets`）。「清單」可收起索引讓地圖變寬。
- 手機：地圖全螢幕，問題清單是底部面板（預設半高，可上拉全高、下拉收成細條；「清單」按鈕同樣可切換）。詳細卡片從底部升起，把手可在約1/3與全高間切換，再下拉關閉；開卡時清單暫收，關卡後恢復。
- 全景視角以投影檢查九座島都落在未被遮住的範圍內，再決定鏡頭距離；直式手機加大視角以容納整座群島。
- 拖曳像地圖（dist/gestures.js）：手指或游標按住的那塊地面會一直跟著走，放手前快速一甩會依速度再滑行一段（最多約目前視距的 18%），停住再放手就不滑。右鍵或「旋轉」模式拖曳旋轉。
- 滾輪往游標所在處平滑縮放，單次滾動最多縮放 1.5 倍。
- 手機雙指：捏合以兩指中間為中心縮放、轉動旋轉、同向滑動平移；兩指並排一起上下滑動則傾斜視角。手指落在島名上也算數，從島名開始拖曳不會誤開卡片。拖曳或滾輪會取消飛行。系統設定「減少動態」時直接切換。
- 首次造訪顯示三步導覽（`writing-island-onboarded`），不動到收藏、筆記與問題（`writing-island-course`，格式不變）。
- 手動驗收可在主控台執行 `__islandView()` 讀取鏡頭目標、距離與角度（唯讀）。

文字層級沿用 `dist/readability.css`，版面骨架在最後載入的 `dist/shell.css`。對標紀錄見 [research/SHELL-LAYOUT.md](research/SHELL-LAYOUT.md)，前輪見 [research/SURFACES-REVIEW.md](research/SURFACES-REVIEW.md)、[research/GAP-ANALYSIS.md](research/GAP-ANALYSIS.md)。

## GitHub Pages

儲存庫 Settings → Pages → Source 選 Deploy from a branch，使用 gh-pages 分支與 /(root)。main 保存完整原始碼，gh-pages 保存 dist/ 的網站內容。所有網站資源使用相對路徑，可在 /gsat-writing-class-island/ 下運作。

修改後先執行 npm test，再提交 main 並推送；發布網站使用：

```sh
git push origin main
git subtree push --prefix dist origin gh-pages
```

目前帳號的自訂 GitHub Actions 工作因付款／額度狀態無法啟動，因此使用 Pages 原生分支發布，未變更帳務設定。

`dist/architecture.js` 以原創幾何建立九種課程微縮建築與隨時段切換的窗光。這些是主題示意，並非真實授課場地。

## 七站旅程

整座島外圍有一條七站旅程，包住中間的三座主題島（01 認識老師、02 教學理念與上課方式、03 家長與學生的疑問；04 學生案例與成果就是獎盃）（`dist/summit.js` 管位置與路線，`dist/journey.js` 管文字與資料）：

1. **① 為何高中一定要學國寫？**（公園綠地，在畫面最前面中央）：兩個主題——「為什麼高中一定要學國寫？」與「為什麼要選擇我？為什麼要選擇這堂課？」，回答寫在 `dist/journey.js` 起點的 `themes`。
2. **② 入口指引牌**：站在兩條路分岔的地方。指引牌上寫著：「寫出高分作文的路不只一條。這座橋呈現的是我經過驗證「有效」且「高效」的學習路徑；另一側呈現大多學生學習作文遇到的誤區。」這句也是第 2 站卡片的第一句。
   - 進入第 2 站時，鏡頭從第 1 站那一側、用較低的角度（`FORK_TILT`）看向指引牌，牌子晚上會微微發光。告示牌放在靠第 1 站的島緣、尺寸不大，朝向一般全景與第 2 站視角的中間，兩個角度都看得到牌面，也不會擋住後面的兩條路。畫面裡左邊是橋（有方向的練習），右邊是木棧道（容易繞遠的練習），兩條路的前段都在畫面裡。停穩後可以自由拖曳；右邊路上的細節，可以請導覽員帶去看。
   - 這不是說只有這座橋是對的、其他方法都錯；橋是老師經過驗證、有效且高效的一條學習路徑，但不是唯一的路；右邊呈現的是大多學生學習作文遇到的誤區，不是指任何老師或補習班。
   - **懸崖**：只背範文、套模板，或埋頭寫卻沒人說哪裡要改；有人會在懸崖邊掉下去。
   - **陡峭山壁**：方法不順但很努力，攀繩爬得上獎盃島，只是很慢，約四成會半路掉下來。
   - **回頭改走橋**：往山壁走的人約四分之一（`TURN_BACK`），走到第一座懸崖會停下來想一想，再回到指引牌改走橋——方法隨時可以調整。
   - 掉下去的學生會從起點（`RESTART`）重新出發。
3. **③ 走上橋**：從指引牌一路平順上升到獎盃，代表「這是我能陪你走的一條路」。點獎盃或橋，橋會由下而上一階一階亮起，鏡頭也跟著亮光移到獎盃；獎盃一直維持金光。
4. **④ 學生回饋**（大學建築）：參考國立臺灣大學總圖書館的形象，沒有任何名稱或標誌。點開可看學生回饋。學生走到大學後分兩種：一半走進門口消失，再從 `SPAWN_FROM`（目前是 ① 為何高中一定要學國寫？）重新出發；另一半不進門，繼續往行事曆、報名、聯繫走。要換重新出發的地點，只改 `dist/summit.js` 的 `SPAWN_FROM`。
5. **⑤ 課程行事曆**：大學旁有往下的石階梯通到這裡。有開班的年級接著報名；年紀還小的只顯示預先登記表單。
6. **⑥ 報名**：私訊索取線上教學視聽、報名表單。
7. **⑦ 聯繫**：聯繫方式，旁邊步道接回起點。

**要填的資料都在 `dist/journey.js`**，留空時網站一律顯示「待老師提供」：

- 起點、橋的說明文字：`STATIONS` 的 `body`。
- 學生回饋：`FEEDBACK`，請先取得學生同意。
- 開班資訊：`CLASSES`，`status` 填 `'open'` 或 `'preregister'`。
- 表單與私訊連結：`LINKS`，必須是 `https://` 開頭。
- 聯繫方式：`CONTACTS`。

連結都會開到外部頁面；網站本身不會代為傳送訊息，也不收集資料。

## 島上的人物

- 人物有臉、頭髮、手腳與配件，走路時手腳交錯（`dist/people.js`）。每個人物只有 6 次繪製，40 人左右也不會太重。
- 人物共 58 位（`dist/walkers.js`）：
  - **學生 47 位**：對應老師目前的教學人數，寫在 `STUDENTS`，人數改變時只改這個數字。
    - 其中 7 位在有實體步道的關聯上抱著筆記本來回走，點下去會打開那條關聯。
    - 其餘學生在島與島之間走動；同時最多 6 位會走到指引牌選路：少數照著指引走上橋（兩條路上的人數約 1 : 7）；其他走右邊的路，有人掉下懸崖或棧道後回到起點，爬山壁的可能半路掉下來，也有人走到第一座懸崖就回頭改走橋。到了獎盃後走到大學，一半進門消失、再從起點重新出發，一半繼續走向行事曆、報名、聯繫；總數維持 47 位。
  - **家長**：每座島 1 位，身形稍高，在島前步道散步。
  - **導覽員**：平常在 ① 為何高中一定要學國寫？（公園綠地）等候。點它再按「跟著導覽員出發」，它會帶你依 `GUIDE_ROUTE` 走：起點 → 指引牌 → 案例與成果（走上橋）→ 學生回饋 → 行事曆 → 報名 → 聯繫。鏡頭會跟著它，到站就打開那站的卡片；按「跟著導覽員走到下一站」再繼續，最後回到起點。
  - **我的角色**：右上「角色」。可設定名字、身分、髮型、衣服顏色，存在 `writing-island-avatar`。行程可選自由漫步、自動逛逛、點地圖指定、前往某座島。
- 點人物時鏡頭會飛近並跟隨；拖曳、滾輪或雙指操作就停止跟隨。工具列「人物」可隱藏其他人物，「日誌」記錄抵達紀錄。暫停或系統減少動態時，人物會停下來。
- 所有人物都是地圖角色，不代表老師本人、真實學生、家長或案例。

## 時間、天氣與植被

- 島上時鐘從打開介面時的 15:20 開始，先停留現實 5 秒，再以現實 1 秒等於島上 5 分鐘前進；開始前進後，4 分 48 秒過完一天。天色、陽光、星星與窗光會平順地在清晨、白天、黃昏、夜晚之間變化，不看使用者的本地時間。工具列的時鐘按鈕顯示島上時間，按下可跳到下一個時段；按「暫停」時鐘也會停。
- 隨機下陣雨（`dist/weather.js`），下雨時天色變灰。白天雨停後，島群後方會出現彩虹。系統開了「減少動態」時不下雨。
- 每座島都有灌木、草叢、花和沿島緣垂下的藤蔓（`dist/decor.js`），會避開步道、橋、滑梯和山壁的接口；岩漿島和小平台除外。
- 家長在一座島散步幾輪後，會沿步道走去別座島，不會一直守在同一座。
- ④ 學生回饋到 ⑤ 行事曆是向下的電扶梯，階梯會一直往下走，人站著被載下去。
- 導覽中的按鈕是「看完了，繼續前進」。
- 地圖名牌改成微透明加背景模糊。這是參考 Puma 前端的做法，數值是自己調的。

## 指引牌、險峻的路與橋

- ② 指引牌是一座完整的島，告示牌指向兩條路：左邊金色的橋（老師經過驗證、有效且高效的學習路徑），右邊險峻的路（大多學生學習作文遇到的誤區）。
- 險峻的路：起伏的木棧道翻過兩座岩石山頭（`pass1`、`pass2`），兩座都是會有人掉下去的懸崖，盡頭是獎盃島下方的岩壁，有四條打結的繩索可以攀上去，很慢、還可能掉下來。
- 走在通往獎盃的橋上時，腳下的階面會發光。
- 點險峻的路的木棧道或陡峭山壁的繩索，也會打開第 2 站，並標示對應的那一段（懸崖或陡峭山壁）。
- 兩條路上同時的人數約 1 : 7（橋 : 險峻的路）。在指引牌直接選橋的比例是 `RIGHT_WAY`（4.5%）；險峻的路走得慢、人停得久，加上有人半路回頭改走橋，實際同時在兩條路上的人數才會是約 1 : 7（以模擬 15 分鐘量測）。開場時也是 2 人在橋上、14 人在險峻的路上。
- 險峻的路上的三種跌落，各有看得懂的原因（`dist/walkers.js` 的 `startDrift`）：
  - **一般失足**：邊走邊慢慢偏向橋緣，身體朝著斜向的路線走，不會突然橫移。多數人會修正回來；沒修正的走到腳踩不到木板時才往下掉，掉的時候還帶著往前的慣性。
  - **大雨沖落**：大雨中先踉蹌一下（腳步放慢、身體搖晃），接著斜向滑步越過橋緣才掉。也有人站穩回來，但比晴天少。
  - **橋板斷裂**：只有腳下的木板斷掉形成缺口時，才會從缺口直接往下掉。
  - 不論哪一種，人都不會突然加速：走偏時的橫向速度會慢慢加快、慢慢放慢（`DRIFT_ACCEL`）；回到車道的橫移比走路慢（`SIDE_STEP`）；在懸崖頂走向崖邊，也是用自己平常的步速。
- 導覽員帶路途中，不小心拖曳或滾動地圖時，放手約 1 秒後鏡頭會自動跟回導覽員。
- 夜晚有城市燈光：建築、島面帶暖色自發光，窗戶與路燈更亮。彩虹改成柔和、顏色漸變、兩端淡出的單一弧。

## 中間三座島的造型

- **01 認識老師**：老師的寫作工作室。低矮寬闊的房子，有大窗、窗內有書桌和檯燈，門口堆著書，長椅上放著稿紙；門前立一支大鋼筆雕塑，作為這座島的地標。
- **02 教學理念與上課方式**：前牆有大黑板的教室，屋頂保留小天文台望遠鏡（代表理念）。課前、課中、課後三個重點的圖釘，各自立在一塊踏石上。
- **03 家長與學生的疑問**：涼亭中間有圓桌和兩張椅子，坐著一位家長和一位學生（額外的地圖角色，不算在 47 位學生內）；四角掛著燈籠，台階旁有「疑問信箱」。
- 重點超過 3 個的島，圖釘沿島的後半圈分散、高度錯開，只顯示編號；滑過、聚焦或選取時才展開名稱。
- 手機或某些角度下，圖釘在畫面上仍可能疊在一起；每一幀畫完後，重疊的圖釘會在畫面上被輕輕推開（`declutterPins`），停穩後不再晃動。點獎盃時，橋亮起與鏡頭拉近的這段先不顯示 04 的圖釘，拉近到獎盃後才出現。
- 點獎盃時，金橋一階一階亮起的亮度，和有人踩在上面時腳下的亮度相同（`FOOT_GLOW`）。

## 站內閱讀 PDF

- 關閉方式：× 、「關閉」按鈕、點視窗外面、手機的返回鍵或返回手勢（不會離開網站）。

## 一分鐘看完旅程（自動播放）

- 右側清單裡「一分鐘看完整趟旅程 ▶」：鏡頭自動依序飛過 7 站，每站停 7–11 秒（說明越長停越久），字幕直接用各站原本的說明（`dist/autotour.js`）。
- 下方字幕列有秒數、進度條、「暫停／播放」「重播」「離開」；空白鍵暫停、Esc 離開。播放時地圖不能拖曳；點任何一站或一座島，會結束播放並打開那一站。
- 播完後可以選「跟著導覽員走一圈」或離開。

## 畫質自動調整

- 一開始用螢幕本來的清晰度（最多 2 倍）。畫面跑不動時（每格超過約 26 ms）一次降一級，最低 1 倍；連續順暢約 6 秒才升回一級（`dist/resolution.js`）。
- 剛打開網頁的前 3 秒、切到背景再回來的那一下，都不算慢。
- 有字的告示牌（第 1 站與第 2 站的牌子）只要在畫面裡、距離近到讀得到（約 16 以內），畫質就鎖在最清楚，再慢也不降；離開後才恢復自動調整。牌面貼圖也開了各向異性過濾，斜看也比較清楚。

## 站內影片

- ⑥ 試聽＆報名的卡片有「課堂片段」：在 `dist/journey.js` 的 `VIDEOS.trial` 填 Google Drive 影片 ID（`driveId`），或兩個 https 的 mp4 網址（`hd` 高畫質、`sd` 低畫質備用），就會出現「在這裡看」按鈕；沒填時顯示「待老師提供」。只放老師願意公開的片段。
